# Renders de producto · Visual System V0.4

Renders CGI **entregados y congelados** (20 ago 2026), optimizados a WebP q90
desde los originales. La fuente de gobernanza es `manifest.json`, alineado con
el evidence register (CV-DATA P2) y el Portfolio Master v0.4:

- **`status: "concept"`** — puede aparecer en la web **solo** con la etiqueta
  de render conceptual visible (E-028: ningún render deriva de golden sample).
- **`status: "blocked"`** — nunca en PDP, campaña ni RFQ. Se suben a la
  mediateca con `evidenceStatus: blocked` para trazabilidad, y el adaptador de
  commerce los excluye del storefront aunque un editor los adjunte por error.

Antes de venta, todo mockup se sustituye por fotografía de la muestra final
(brand book §22). El asset 12 del board (tenis de mesa) está **retirado**:
fuera de arquitectura, solo trazabilidad histórica.
